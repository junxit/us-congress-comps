# us-congress-comps

Statute Compilations — non-codified law as amended, snapshotted daily because govinfo overwrites it in place and keeps no archive.

Generated by [`us-congress-pipeline`](https://github.com/junxit/us-congress-pipeline). This repository holds data only: nothing in it is edited by hand, and all of it can be rebuilt from the upstream sources at any time.

**Is this still maintained?** [`STATUS.md`](https://github.com/junxit/us-congress-pipeline/blob/main/STATUS.md) in the pipeline carries the date the daily job last ran. If that date has stopped moving, so has this.

## What is here


Built from govinfo COMPS.

git clone git@github.com:junxit/us-congress-comps.git

## What to watch out for

This is a **derived copy**, not an official source of United States law. It is generated automatically and published without review. For authoritative text, use [uscode.house.gov](https://uscode.house.gov) or [govinfo.gov](https://www.govinfo.gov).
